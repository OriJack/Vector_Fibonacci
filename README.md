# Vector_Fibonacci
El usuario determina el tamaño del vector y llena el mismo de numeros al  azar. Se hacen las siguientes operaciones: 

1)contar los valores que sean primos en las posiciones que pertenezcan a la serie fibonacci que sea un multiplo de 3

2) Sumar los valores primos en posiciones primas que sean multiplos de 3,4,5,7
   
4) Ordenar el vector con el metodo de la burbuja de mayor a menor solo con los primos que aparezcan en la serie Fibonacci

4)Promediar los valores que hay en el vector e indicar en numero (N) mayor al promedio y los numeros menores al promedio y su posicion despues de ordenar en el punto 3

Se debe utilizar un Frontend con HTML JavaScript y CSS, y un backend con PHP.
